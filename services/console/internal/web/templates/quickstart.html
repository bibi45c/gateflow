Base URL: {{$base}}. FlowGate speaks the Anthropic Messages API (POST /v1/messages) and the OpenAI Responses API (POST /v1/responses). Create a key under API keys and put it in GATEFLOW_API_KEY. mock-chat streams a readable answer like a real model; see Models for the rest.

curl

export GATEFLOW_API_KEY=gf_...
curl -N {{$base}}/v1/messages \
  -H "x-api-key: $GATEFLOW_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model":"mock-chat","max_tokens":256,"stream":true,
       "messages":[{"role":"user","content":"Hello"}]}'

Codex CLI

~/.codex/config.toml (or the folder in CODEX_HOME):

model = "mock-coding"
model_provider = "gateflow"

[model_providers.gateflow]
name = "GateFlow"
base_url = "{{$base}}/v1"
wire_api = "responses"
env_key = "GATEFLOW_API_KEY"

OpenCode

opencode.json in the folder where you start OpenCode:

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "gateflow": {
      "npm": "@ai-sdk/anthropic",
      "name": "GateFlow",
      "options": {
        "baseURL": "{{$base}}/v1",
        "apiKey": "{env:GATEFLOW_API_KEY}"
      },
      "models": {
        "mock-coding": {"name": "Mock coding", "limit": {"context": 40960, "output": 4096}}
      }
    }
  },
  "model": "gateflow/mock-coding",
  "enabled_providers": ["gateflow"]
}

The repository's docs/clients/codex.md and docs/clients/opencode.md have the full, tested setups.
